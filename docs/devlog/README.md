# Development Log Entries

Every entry is one file under [`entries/`](entries/), named `YYYY-MM-DD-<slug>.md`, and these files are the whole log. How to search the log, add an entry, and build a local reading view: [DEVELOPMENT_LOG.md](../../DEVELOPMENT_LOG.md).

The `view/` directory is generated by `pnpm devlog:build` and is git-ignored.

# 2026-10-03 — Hermes swims as a 2D mermaid, and stays pinned like OpenClaw

### What changed

**A mermaid, not a floating head.** On every terrarium without the 3D aquarium (Android 2D and e-ink terrariums, ESP32 LCD terrariums, Pixoo 64), Hermes was the official Nous girl mark drifting on its own: a bust with no body, which the user found eerie. `scripts/generate-hermes-mermaid-2d.mjs` now builds one 2D mermaid. The head is the official mark, paths unchanged; only its cropped bottom edge fades (y 21.6 → 24) so the bust melts into a kelp tail. The tail is a cubic centerline with a hip → peduncle width profile, a shadow rim and a two-lobed fluke, coloured from the kelp tokens read out of `design/tokens.css`. From that one geometry it emits the canonical SVG, TS and Kotlin path data, ESP32 42×60 layer masks and Pixoo 28×40 layer masks (TS + Swift), behind a `--check` drift test. Each surface draws the layers tail → rim → fluke → head, and the fluke beats while she works. Deck keys, session lists, cards, Timebox and the 32-px compact view keep the plain mark, which reads fine there.

The design took five rounds. A straight tail under the bust read as a bust on a vase; a hip band read as a plate; only fading the portrait's crop into a tail that starts behind the head read as one body. At 14×20 the Pixoo zoom was blocky, so its masks are 28×40.

**Pinned like OpenClaw.** Hermes is a general-purpose assistant like OpenClaw, so it now sorts with it at rank 0 (TS `agentTypeRank`, Swift `DashboardDataRules` and the D200H preview, Kotlin `agentTypeRank`, which had also fallen behind on Kiro). A running Hermes CLI stays on screen while its process lives: the observer now sends `platform`, and the five-second process sweep (Node `sweepDeparted`, Swift `HermesObserverGate`) refreshes the silence timer of a live CLI conversation. Gateway conversations keep the 30-minute TTL, because a messaging gateway never finalizes a chat and would otherwise accumulate rows.

# 2026-08-31 — NM 스피커는 설정이 아니라 볼륨이었고, EPD47 깜빡임은 clear 자체였다

### 문제

전날 라운드의 미검증 두 항목을 실기로 닫으려다 둘 다 원인이 예상과 달랐다.
NM은 `audio_out`을 광고하는데 소리가 안 났고, EPD47은 탭 한 번에 "엄청 많이"
깜빡였다.

### 해결

**NM 스피커.** 코덱은 0x18에 응답하고, 벤더의 검증된 레지스터 시퀀스대로
초기화되고, 앰프 인에이블이 HIGH이고, I2S가 드롭 없이 전 샘플을 소비했다 —
그런데 무음. 벤더 참조 펌웨어(`RockBase-iot/NM-EPD-420`,
`src/tests/test_t4_codec.h`)를 클론해 레지스터를 1:1 대조한 결과 **남은 유일한
실측 차이가 DAC 볼륨**이었다: 우리 `0x32=0x9B`(-18 dB) vs 벤더 `0xD3`(+10 dB),
28 dB·진폭 25배. 70이라는 기본값은 IPS10 Class-D 앰프에서 귀로 고른 값이고
그건 코덱이 아니라 **앰프 속성**이다. `BOARD_SPK_DEFAULT_VOLUME`으로 분리하고
NM은 100(0 dB, 부스트 없는 최댓값). 실기에서 440 Hz 톤 가청 확인.

**EPD47 깜빡임.** 탭 경로를 추적하니 탭 한 번은 정확히 `epd_clear()` **한 번**을
부른다 — 버그가 아니라 clear 자체의 비용이다(epdiy 전면 클리어는 흑백 반전을
여러 번 돈다). 그래서 clear를 내용 변화 경로에서 제거했다. 캔버스가 마지막으로
쓴 프레임을 PSRAM에 하나 더 들고(259,200 B, 실패 시 기존 clear 경로로 degrade),
내용이 바뀌면 그 프레임을 `epd_draw_image(WHITE_ON_WHITE)`로 종이로 되돌려
**잉크가 실제로 있는 픽셀만** 지운다. 하드 파형은 원래 목적인 주기적 안료
리셋에만 남기고, 그때 retained frame을 백지로 되돌려 다음 지우기가 이미 없는
잉크를 쫓지 않게 했다.

### 핵심 설계 결정

**한 방향으로만 틀릴 수 있는 진단은 진단이 아니다.** 첫 레지스터 덤프가
`PA(41)=0 / CODEC_EN(44)=0`을 보고해 "앰프가 꺼져 있다"로 읽힐 뻔했다. 실제로는
`GPIO_MODE_OUTPUT`이 입력 버퍼를 끄기 때문에 `gpio_get_level()`이 무엇을 구동하든
0을 돌려준다 — 켜져 있는 앰프를 두고 꺼졌다고 보고한 것이다. 두 핀 모두
`GPIO_MODE_INPUT_OUTPUT`으로 바꿨다(드라이버는 동일, 상태만 읽힘).

**데몬의 serial `device_info`는 캐시이고, uptime뿐 아니라 카운터도 낡는다.**
탭 전후 `/devices`가 `repaint/full = 16/6`으로 완전히 동일하길래 보드를 직접
읽으니 실제로는 `57/19`였다 — 41 repaint 뒤처진 값이다. **이 세션에서 앞서
보고한 88% → 60% → 42% 리프레시 비율은 전부 그 낡은 캐시를 읽은 것이라
무효다.** 메모리에 이 함정이 이미 적혀 있었는데도(`esp32-serial-deviceinfo-
cache-seed-stale`) 그대로 밟았다. 카운터를 인용하려면 보드에서 직접 읽는다.

**같은 술어를 두 곳에서 유도하지 않는다.** 차등 지우기 첫 구현은 `refresh()`
안에서 `partialCount`/`lastFullMs`로 anti-ghost 여부를 다시 유도했는데, 그건
직전 커밋에서 탭 히트 테스트에서 막 제거한 모양이다. `Erase`로 `render()`에서
한 번만 결정해 넘긴다.

**플래시 실패의 절반은 앱이 포트를 되잡은 것이었다.** AgentDeck 앱이 재시도
사이에 자동 재실행되어 시리얼을 다시 점유했고, esptool은 그것을 "Serial data
stream stopped"로 보고한다. 종료와 업로드를 한 명령에 붙이면 바로 성공한다.

### 남은 것

EPD47 차등 지우기의 실물 체감 확인(설치 완료, 사용자 확인 대기).
NM 마이크는 여전히 보류 — 종이용 캡처 표시기가 선행 과제.
데몬 캐시가 낡은 채로 서빙되는 것 자체는 별도 이슈로 남아 있다.

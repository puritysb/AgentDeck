# 2026-09-21 — Drain Node daemon sockets before handover

- Investigated macOS fallback-port recovery during the 1.4.0 release soak (#314). A standalone Network.framework listener reproduced `EADDRINUSE` after a Node HTTP listener closed a used connection; a listener with no accepted requests could be rebound immediately. Completed connections aged out after approximately 40 seconds. This is distinct from a live competing listener.
- The Node shutdown path waited for asynchronous module teardown before closing the transport, and did not explicitly reset all accepted HTTP, SSE and upgraded WebSocket sockets. Track raw accepted sockets and reset them at the start of shutdown, before module teardown. Flush the `/shutdown` response before initiating this drain.
- Regression tests use real TCP peers for an open HTTP event stream and an upgraded connection, assert reset delivery, and bind a successor listener on the same port. Build, typecheck and the full suite passed (4,670 tests, two skipped); protocol generation had no drift and token mirrors matched.
- Installed npm candidate build `f95b030d2fea` on the test Mac. After stopping it, the existing Apple 1.4.0 candidate recovered from port 9121 to 9120 without restarting the app, approximately 145 seconds after CLI stop. Logs show the canonical-port retry at 13:21:20 UTC and successful listener at 13:21:25 UTC. The existing 120-second failed-bind cooldown still applies; this change does not promise instantaneous handover or eliminate normal TIME_WAIT.
- Also reproduced a launchd restart race: bootstrap/kickstart returned success while the old job was still unloading, then the service disappeared. Wait for `launchctl print` to report the service absent before continuing the stop/restart path. Unknown results retain the wait; a 20-second budget fails explicitly. Regression tests cover delayed removal and unknown/permanently loaded jobs. The installed candidate subsequently restarted successfully on 9120 under launchd.
- Design lint: 89 existing violations in a clean archive; the built checkout adds three ignored Ulanzi JavaScript findings, with no source regression.
- No Apple source change is included. This transport correction belongs in the unpublished npm 1.4.0 candidate. The observation does not by itself complete the release's three-mode end-to-end soak or establish results on other operating systems.

# 2026-09-23 — IPS10 작업 중심 UI와 개인 OpenClaw 음성 호출

IPS10의 기본 화면을 현재 작업/최근 결과 중심으로 줄이고 긴 기록은 탭 상세로
옮겼다. 길게 누르기는 수동 음성 대상 선택, 하단은 호출어 켜기/끄기와 중지다.
가로/세로 상세 창 경계와 글자 크기를 수정하고 실제 LVGL 상호작용을 검증했다.
기존 작업 상태 기반 장면은 유지했다. 새 실시간 3D 렌더러를 구현한 것은 아니다.

IPS10 ES8311 수신을 단일 작업이 소유하며 TFLite Micro 한국어 호출어 모델과
자동 발화 종료를 처리한다. PSRAM에 특징 처리/모델/녹음 버퍼를 두고 사용하지
않는 내부 12 KB 스트리밍 링을 제외해 업로드 시 내부 여유가 56 KB에서 80 KB로
늘었다. 재생 중 호출 감지를 멈추고 중지한 응답의 다운로드/재생도 취소한다.

Node daemon은 `openclaw-personal`을 `agent:main:main`으로 고정 라우팅하고,
접수된 실행 ID와 세션이 일치하는 완료만 읽어 준다. Mac Studio의 Apple Speech
권한 대기가 끝나지 않아 기존 ARM64 Whisper/large-v3-turbo를 명시적인 로컬
인식 백엔드로 연결했다. 음성 수신 HTTP 응답을 인식 완료와 분리했다. TTS는 기존
네이티브 helper를 사용한다. 재시작 후 daemon 빌드 `ad38d0e5312e`를 확인했다.

무선 OTA가 청크 3290에서 시간 초과돼 식별된 IPS10 USB 경로로 전환했다.
ESP32-P4/16 MB 확인, 전체 이미지 해시 검증, 하드 리셋과 실행 epoch
`1790127440` 읽기까지 완료했다. 실기기 합성음 재생 시험에서 호출어 감지,
171,840-byte 녹음 업로드(HTTP 200), 개인 에이전트 접수, 응답 260,292-byte
다운로드/재생과 호출 대기 복귀를 확인했다. 호출어 없는 문장과 호출 후 침묵도
시험했다. 사람의 원거리 발화 정확도나 장시간 오탐률 검증으로 확대해 해석하지 않는다.

연속 시험에서 81,920/200,512 bytes 지점의 재전송 정체를 추가로 발견했다.
네트워크 소유 작업에서 비차단 전송을 사용하고 WS/serial 수신도 처리하도록
수정한 뒤 같은 부팅에서 두 요청의 업로드와 응답 재생을 완료했다. 응답 전송의
8 KB 버스트 때 내부 최소 여유가 2 KB까지 내려가는 현상도 관찰해 host가
1 KB/20 ms로 내려보내도록 조정했다. 마이크 WAV 재인식에서는 단어 치환이
관찰됐고 한 차례 호출 누락도 있었다. 전송 경로 검증과 한국어 인식 정확도/원거리
검증은 별개다. 최종 404,812-byte 응답의 전체 다운로드와 재생 전달을 확인했으며,
해당 부팅의 내부 최소 여유는 63 KB를 유지했다.

카메라 SCCB 읽기로 OV02C10 ID `0x5602`를 확인했다. CSI 프레임 수집과 비전
모델은 구현하지 않았다. 재실에 따른 정보 밀도 조절과 사용자가 요청하는 사진
질의가 다음 실험 후보이며, 자세한 범위와 근거는 [음성 문서](docs/wake-word.md)에 있다.

검증: build/typecheck, 305개 파일의 4,654개 테스트 통과(2 skipped), protocol
생성 무변경, 디자인 토큰 동기화, 가로/세로 native simulator 상호작용 통과.
기존 HTML/JS의 디자인 lint 위반은 수정 범위 밖에 남아 있다.

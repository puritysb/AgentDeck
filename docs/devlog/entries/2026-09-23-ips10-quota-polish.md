# 2026-09-23 — IPS10 quota hierarchy and Antigravity plan-only restoration

The prior aquarium implementation mistakenly exposed Antigravity's raw local credit count, contradicting the existing `shared/src/format-utils.ts` and `UsageFormat::formatAgyPlan` dashboard contract. Removed the credit widget and its participation in quota visibility/counts. A confirmed plan appears only as a compact header chip (`AGY Pro`); credit-only and unknown-plan data create no quota rail or chip. The domain rule now explicitly records this existing constraint to prevent another regression.

Quota rings keep an 88px diameter and 6px stroke for every provider count. Provider names align with their gauge group; percentage, used-window label and optional reset text have separate visual levels. Cyan has the same usage meaning in both windows; amber still marks 90% or higher. A single known window stays centered, and the rail height follows actual content instead of leaving a full-height empty box. The implementation reuses six fixed gauge widgets and one fixed subscription chip, replacing the previous seven-gauge/four-provider pool without per-update allocation.

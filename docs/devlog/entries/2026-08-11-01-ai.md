# 2026-08-11 — 외부 기여와 AI 보조 유지보수의 공개 계약 정립

### 배경

- 저장소는 활발히 배포되고 있었지만 `CONTRIBUTING.md`, `SECURITY.md`, 행동강령,
  이슈/PR 템플릿이 없어 외부 기여자와 보안 제보자가 따라야 할 공개 경로가 없었다.
- 코딩 에이전트를 폭넓게 사용하면서도 자동 리뷰의 권한, 데이터 경계, 성과 측정 기준이
  저장소 정책으로 명시되지 않아 활동량과 실제 유지보수 효과를 구분하기 어려웠다.

### 변경

- 기여 절차, 보안 비공개 신고, 행동강령과 구조화된 bug/feature/PR 템플릿을 추가했다.
- `docs/ai-assisted-maintenance.md`에 사람의 최종 책임, 공개 OSS 범위, 비밀정보 제외,
  provider-neutral 검증, PR·이슈·릴리스·보안 리뷰의 허용 범위와 측정 지표를 정본으로
  기록했다.
- README의 프로젝트 문서와 Community 섹션에서 새 공개 계약으로 진입할 수 있게 했다.

### 검증

- `pnpm design-system:check`, `pnpm docs:check`, 새 Markdown/YAML 대상 Prettier 검사,
  Ruby Psych YAML parse, `git diff --check` 통과.

# 2026-08-13 — Apple 1.0.6 build 5101 심사 제출

### 승인 및 공개

- Apple 심사 승인 후 자동 출시가 적용됐다. 미국 공개 App Store의 기본 iPhone/iPad
  페이지와 `?platform=mac` 페이지가 모두 **Version 1.0.6**과 새 feedback-flow 릴리스
  노트를 표시해 두 플랫폼의 공개 배포를 확인했다.
- Apple lookup API와 이 Mac의 MAS 영수증 설치본은 확인 시점에 각각 iOS 1.0.5와 macOS
  1.0.5 (4701)를 계속 반환했다. 공개 제품 페이지보다 캐시·자동 업데이트가 늦을 수 있으므로
  이 값만으로 최신 공개 버전을 되돌려 판단하지 않는다.

### 제출

- App Store Connect에서 iOS와 macOS 각각 새 `1.0.6` 버전 레코드를 만들고 최종 빌드
  **5101**을 연결했다. 4901과 5001은 제출에 사용하지 않았다.
- 영문·한국어·일본어 `What's New`를 `docs/appstore-metadata-draft.md`의 1.0.6 문구로
  채웠고, 플랫폼별 심사 메모도 `apple/APP_REVIEW_NOTES.md`의 최신 평점 요청 및 로컬
  개인정보 경계와 일치시켰다.
- 현지화된 `What's New` 누락으로 처음 생성된 macOS 0-item 초안은 삭제한 뒤 정상
  초안을 다시 만들었다. 최종적으로 남은 초안은 없다.
- iOS와 macOS를 각각 심사에 제출했고 승인 후 자동 출시 설정을 유지했다. 두 플랫폼 모두
  **1.0.6 (5101)**로 승인·공개됐다.

# 2026-08-07 — Stream Deck device profiles and readable classic-key labels

The plugin now maps every DeviceType currently documented by Elgato instead of
folding unrecognized hardware into the original Stream Deck family. Device
registration and action rendering share the same canonical mapping, including
distinct identities for Pedal and Corsair Voyager devices.

Session tiles use a larger, earlier-wrapping text profile on original 72px
Stream Deck keys while retaining the standard profile on XL, Plus, and other
higher-resolution keys. The selection is automatic and adds no diagnostic or
machine-specific logging.

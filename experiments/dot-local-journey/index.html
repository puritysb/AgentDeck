    실제로 확인한 내용

    실제 Dot이 연결된 Mac에서 Swift 클라이언트를 실행하고, 격리된 Swift 호스트의 요청을 읽고 완료를 보고했어요. 6회 호출이 모두 성공했고 합성 문맥의 합 122가 일치했어요.

    연결 거절·승인, 재시작 후 복원, 초기 토큰 수명 이후 조회, 철회 후 접근 거절을 확인했어요.

    아직 출시 조건인 내용

    설치된 로컬 MCP 플러그인의 자동 도구 노출, 일반 사용자의 GUI 연결, 실제 AgentDeck 앱과 장비 화면, Store 서명 및 신규 사용자 검증이 남아 있어요.

    검증에서는 클라이언트를 명시적으로 실행했어요. 이 모형의 버튼이 제품에 구현됐다는 뜻은 아니에요.

    데이터가 가는 곳

    Dot · OpenAI ↔ 연결한 Mac ↔ AgentDeck

    이 로컬 경로에 AgentDeck 개발자의 중계 서버는 필요하지 않아요. 공유한 문맥과 결과는 OpenAI에서 처리해요. 인터넷 없는 서비스는 아니에요.

    AgentDeck 연결을 철회해도 Dot의 컴퓨터 접근 권한은 별도로 남아요. 이미 OpenAI에 전달된 자료가 소급 삭제되거나 진행 중인 Dot 작업이 취소되는 것도 아니에요.

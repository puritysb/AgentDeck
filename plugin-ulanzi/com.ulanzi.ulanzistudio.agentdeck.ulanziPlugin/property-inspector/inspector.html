AgentDeck

One key per AI coding session — live state on the key, and your answer sent back.

Looking for the AgentDeck daemon…

Opens in a separate window, which may appear behind the Ulanzi Studio window.

Setup in 3 steps
1

Run the AgentDeck daemon

Install AgentDeck Dashboard — free on the Mac App Store, macOS 26 or later — and open it. No terminal needed.

On an earlier macOS, or where the App Store app is not offered, use Terminal:

Open Terminal or PowerShell and run:

npx @agentdeck/setup

Node.js 22+ is the only prerequisite. The Claude and Codex CLIs are optional — install neither and setup still completes.

2

Start an AI coding agent

In any project folder, start your agent the way you normally do — claude, codex or opencode. There is no AgentDeck-specific command.

Desktop apps count too: macOS picks up Codex sessions from the ChatGPT app once Codex integration is registered — the terminal setup does it for you, and the App Store app asks in Settings.

3

Fill your keys

Drop the AgentDeck action on every key you want to use — it is the only action there is, and each key decides for itself what to show. The layout spreads over exactly the keys you placed: one per session first, then the answer keys, mode, stop and usage as room allows.

Before steps 1 and 2 are done, the middle key reads OFFLINE and the rest sit dim. That is the plugin working — it is telling you the daemon is the missing piece.

AgentDeck is a thin client, like an OBS plugin: it draws what the local daemon reports and bundles no daemon of its own.

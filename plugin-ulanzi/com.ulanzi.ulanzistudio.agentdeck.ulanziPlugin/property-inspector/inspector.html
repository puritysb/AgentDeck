Getting started
1
Run the AgentDeck daemon on this computer. Either way works:
macOS — install the free AgentDeck Dashboard from the Mac App Store and open it. No terminal.
macOS or Windows — run npx @agentdeck/setup (needs Node.js 22+).
2
Start any AI coding agent the way you normally do — claude, codex or opencode. No AgentDeck-specific command is needed.
3
The keys fill themselves in: one key per live session, showing the agent, the project and whether it is working, idle, or waiting on you. Press a key to focus that session, or to answer it when it is waiting.

This plugin is a thin client — it draws what the local daemon reports and bundles no daemon of its own. Until step 1 and step 2 are both done, the keys stay on OFFLINE. That is expected, not a failure.

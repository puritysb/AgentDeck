# Glance common rasterizer

The Swift macOS daemon statically links this library. Node uses the prebuilt
`@resvg/resvg-js` **2.6.2**, which embeds the same `zimond/resvg` revision
`3495d870`. This is deliberately not the current upstream resvg release.
`Cargo.lock` preserves the fork's renderer/font-layout dependency versions.
The bundled font list and FNV content identity are generated by
`pnpm generate-glance-policy` (the wire content signature remains FNV-1a).
System fonts and external image resolution are disabled. No subprocess,
renderer executable, interpreter or downloaded runtime ships in the app.

Build prerequisites: Rust 1.90.0 (CI compiler) with `aarch64-apple-darwin` and
`x86_64-apple-darwin` targets, Xcode and XcodeGen. The Xcode pre-build phase runs
`apple/scripts/build-glance-raster.sh`, builds each requested architecture and
combines the static libraries with lipo. The iOS app does not link the renderer.
Build tools are developer prerequisites, never app setup requirements.

Geometry, layout units, WMO icon classification, Bayer thresholds and font
identity live in `shared/glance-frame-policy.json`; SVG icon paths and layout
composition remain canonical in `bridge/src/glance-frame.ts`. The generator
emits Swift constants/icons and the TS policy. Swift implements the layout;
the macOS parity gate compares the SVG string, every packed byte, signatures,
orientation and decoded PNG pixels using the real compiled implementations.
Renderer/font/policy/rotation identity is included in the clock-blanked SVG
signature so changing the rendering policy invalidates old conditional frames.

Both sides composite premultiplied RGBA onto white and use integer BT.601
luminance `(299R + 587G + 114B + 500) / 1000`, then rotate, Bayer-dither and pack
MSB-first rows with white=1 and zero row-tail bits. The PNG is expanded from
those packed bytes; PNG container encodings need not be identical.

Redistribution notices and source links are bundled in
`apple/AgentDeck/Resources/Glance-ThirdPartyNotices.txt`. The resvg/usvg fork is
unmodified MPL-2.0; this wrapper's source is in this directory. Dependency and
font notices accompany the app. A resvg-js upgrade must update this engine and
its lockfile together and pass the exact-byte parity gate on macOS.

Universal macOS builds require both `aarch64-apple-darwin` and
`x86_64-apple-darwin` standard libraries for the **same compiler identity**.
CI pins Rust 1.90.0 and installs both targets. With rustup, use
`rustup toolchain install 1.90.0 --profile minimal --target aarch64-apple-darwin,x86_64-apple-darwin`
and select that toolchain for the build. A Homebrew ARM-only compiler cannot
consume an independently downloaded Rust distribution's standard library merely
because their version numbers match. `CARGO` selects the build-time executable;
no compiler or helper is included in the app.
